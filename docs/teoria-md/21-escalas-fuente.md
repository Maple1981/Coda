## Alcances de las escalas

Transformaciones desde una escala para llegar a otra.

Partiendo de una escala mayor / jónica, tenemos:

C D E F G A B

La escala menor natural / eólica, con el 3º, 6º y 7º grado bemoles.

C D E♭ F G A♭ B♭

El modo lidio, que tiene el 4º sostenido.

C D E F# G A B

El modo mixolidio, que tiene el 7º bemol.

C D E F G A B♭

Partiendo de esa menor natural / eólica:

La menor armónica, con el 7º grado en becuadro.

C D E♭ F G A♭ B

La melódica descendente, que es idéntica a la menor.

C D E♭ F G A♭ B♭

El modo dórico, que tiene el 6º grado en becuadro.

C D E♭ F G A B♭

El modo frigio, que tiene el 2º bemol.

C D♭ E♭ F G A♭ B♭

El modo locrio, que tiene el 5º bemol.

C D♭ E♭ F G♭ A♭ B♭

Partiendo de esa menor armónica tenemos:

La melódica ascendente, con el 6º grado en becuadro.

C D E♭ F G A B
