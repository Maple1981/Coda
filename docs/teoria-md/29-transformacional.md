Teoría transformacional o neo-riemanniana.

https://www.youtube.com/watch?v=XPtQzrQmX6E&ab_channel=CountBlissettTeoriaMusical

https://filmmusicnotes.com/topic/4b-1-overview-and-voice-leading/

Las operaciones son reversibles y retornan al acorde inicial.

Con las operaciones básicas L, P y R es posible describir cualquier transformación triádica.

Cuando se usan en combinación, las letras simplemente se juntan: LP, PL, etc.

P. ej. RP sobre I transforma el I en vi (R), y a continuación en VI (P). C->A. LP transforma el I en iii y acto seguido en III. C->E.

En mayor, el movimiento PL equivale a un préstamo de I-bVI (I pasa a i y luego a bVI), y es muy usado en temas de amor, a menudo sobre un pedal de tónica.

| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| BÁSICAS |  |  |  |  |  |  |  |  |  |
| T | Transposition (subíndice = nº st) |  |  | T2P = C -> Dm | T2P = Cm -> D |  |  | Cambios de pitch | Renovación. |
| L | Leading-tone (cambia calidad acorde) | I -> iii | i -> bVI | C -> Em | Cm -> A♭ | Bajar fundamental un st. | Subir quinta un st. | Produce acorde a una tercera mayor /sexta menor de distancia. | Cambio de ambiente, majestuoso/melancólico y viceversa |
| P | Parallel (escala paralela) | I -> i | i -> I | C -> Cm | Cm -> C | Bajar tercera un st. | Subir tercera un st. | Va al acorde de tónica de la tonalidad paralela. | Dos caras, ambivalencia. |
| R | Relative (escala relativa) | I -> vi | i -> bIII | C -> Am | Cm - E♭ | Subir quinta dos sts. | Bajar fundamental dos sts. | Produce acorde a una tercera menor / sexta mayor de distancia. Va al acorde de tónica de la tonalidad relativa. | Sabor tonal y diatónico. |
| DERIVADAS |  |  |  |  |  |  |  |  |  |
| S | Slide (tríada que comparte tercera). Convierte un acorde mayor en menor a distancia de semitono, y viceversa. Es decir, retiene la tercera y mueve la fundamental y quinta un semitono arriba o abajo. Es equivalente a un RPL (o LPR). | I -> iib | i -> VII# | C -> C#m | Cm -> B | Subir fundamental y quinta un st. | Bajar fundamental y quinta un st. | Preserva la tercera. | Fricción, incomodidad, distancia.  Lo incomprensible, incredulidad. Tonalidad ambigua; ambos acordes no pueden pertenecer a la misma escala. https://filmmusicnotes.com/topic/fh1-3-3a-1/ |
| N | Near fifth (tríada cuya quinta es la fundamental del acorde mayor o cuya fundamental es la quinta del acorde menor, PERO invirtiendo la calidad del acorde) | I -> iv | i -> V | C -> Fm | Cm -> G | Subir tercera un st. y quinta uno/dos st. | Bajar fundamental un st. y tercera uno/dos st. |  | Sabor modal. |
| F | Far fifth (tríada cuya fundamental es la quinta del acorde mayor o cuya quinta es la fundamental del acorde menor, PERO invirtiendo la calidad del acorde) | I -> v | i -> IV | C -> Gm | Cm -> F | Bajar fundamental y tercera | Subir tercera y quinta |  | Evoca naturaleza, ominoso portento, veneración, vastedad, profundidad. |
| H | Hexatonic pole (tríada más cercana que no comparte ningún tono = LPL o PLP). |  |  | C -> A♭m | Cm -> E | Bajar fundamental y tercera un st y subir quinta un st. | Bajar fundamental un st y subir tercera y quinta un st. | Cambio total de contexto, produce acorde inverso a una tercera mayor de distancia. | Evoca catástrofe, muerte trascendencia, inquietud. |
| D | Dominant (ir a la tríada de la misma calidad, cuya quinta es la fundamental del acorde = T5) | I -> IV | i -> iv | C -> F | Cm -> Fm |  |  | Relación diatónica de V->I o vi->i. |  |
| I | Identity (dejar la tríada sin cambiar) | I -> I | i -> i | C -> C | Cm -> Cm | No hacer nada. | No hacer nada. |  |  |
| SUPLEMENTARIAS |  |  |  |  |  |  |  |  |  |
| f'(x) | Forma inversa de transformación (obsérvese el apóstrofe) |  |  | D'(C) = C -> G | D'(Cm) = Cm -> Gm |  |  |  |  |
| fg(x) | Componer múltiples transformaciones en orden de izquierda a derecha. |  |  | LSP(C) = C -> E♭m | LSP(Cm) = Cm -> A |  |  |  |  |
| f *g(x) | Énfasis o clarificación de una subdivisión particular de una transformación compuesta. |  |  | L*SP(C) = C -> E♭m | L*SP(Cm) = Cm -> A |  |  |  |  |
| -f | Transformación vaga o imprecisa, donde la entrada o la salida no son tríadas puras. |  |  | -LP(C) = C -> Emaj7 | -LP(Cm) = Cm -> A♭m maj7 |  |  | Usada para tríadas incompletas, acordes suspendidos, aumentados o disminuidos, acordes con séptimas, poliacordes, etc. |  |
