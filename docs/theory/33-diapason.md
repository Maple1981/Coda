Una octava se compone de 6 tonos, es decir, 12 semitonos. Por eso la primera octava del diapasón termina en el traste 12.

| Columna 1 | Columna 2 | Columna 3 | Columna 4 | Columna 5 |
| --- | --- | --- | --- | --- |
| Notación anglosajona |  |  |  | Truquillos para encontrar notas rápidamente |
| Do | C |  |  | En el traste 12 están las seis notas de las cuerdas al aire, una octava más alta. |
| Re | D |  |  | Las cuerdas 6 y 1 coinciden |
| Mi | E |  |  | En la 6ª y la 5ª cuerda, podemos encontrar la octava de cualquier nota buscando dos cuerdas más abajo y dos trastes más altos (agudos) |
| Fa | F |  |  | Podemos hacer lo mismo en la cuarta y tercera cuerda, buscando su octava en la segunda y primera cuerda respectivamente, pero debemos subir a 3 trastes en lugar de 2. |
| Sol | G |  |  | Cualquier nota se encuentra también bajando 5 trastes en su cuerda inferior. Si buscamos en la tercera cuerda, deberemos bajar 4 trastes en lugar de 5 |
| La | A |  |  | El traste 7 de todas las cuerdas excepto la 2ª equivale a la cuerda superior al aire, una octava más aguda. |
| Si | B |  |  | El traste 5 de todas las cuerdas excepto la 3ª equivale a la cuerda inferior al aire |
|  |  |  |  | Mediante los acordes mayores en sexta cuerda con cejilla, sabiendo sus intervalos: nota de 6ª cuerda tónica I. Nota de 5ª cuerda, V. Nota de 3ª cuerda, III |
|  |  |  |  | Mediante los acordes mayores en quinta cuerda con cejilla, sabiendo sus intervalos: nota de 5ª cuerda tónica I. Nota de 4ª cuerda, V. Nota de 2ª cuerda, III |
|  |  |  |  | Cualquier nota de la quinta cuerda se encuentra una octava más aguda en la cuerda segunda, si bajamos dos trastes hacia graves. |

NOTA: "bajar" significa subir trastes en el mástil. "Subir" significa bajar trastes en el mástil.
