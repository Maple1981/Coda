## Soundfonts MIDI.js / FluidR3_GM

Archivos locales: `soundfont/*.js`

Instrumentos distribuidos actualmente:

- `acoustic_grand_piano`
- `acoustic_guitar_nylon`
- `drawbar_organ`
- `percussive_organ`
- `pizzicato_strings`
- `string_ensemble_1`
- `synth_drum`

Fuente: proyecto `gleitz/midi-js-soundfonts`, colección de soundfonts General MIDI prerenderizados para MIDI.js.

URL del proyecto: https://github.com/gleitz/midi-js-soundfonts

URL pública de los soundfonts: https://gleitz.github.io/midi-js-soundfonts/

Banco usado: `FluidR3_GM`, generado a partir de `FluidR3_GM.sf2`.

Licencia declarada para `FluidR3_GM`: Creative Commons Attribution 3.0 (CC BY 3.0).

URL de licencia: https://creativecommons.org/licenses/by/3.0/

Cambios: archivos vendorizados localmente para carga offline desde `soundfont/`; no se han modificado musicalmente las muestras.

Uso en CODA: reproducción de notas, acordes y futuras progresiones desde el navegador.
